##  Task 1: Iris Dataset Exploration & Visualization

### Objective

The goal of this task was to explore the dataset and understand patterns using basic visualization techniques.

###  Dataset

I used the Iris dataset, which is easily available through seaborn.

###  What I did

* Loaded and explored the dataset using pandas
* Checked basic details like shape, columns, and summary statistics
* Created scatter plots to see relationships between features
* Used histograms and boxplots to understand distribution and detect outliers

###  Key Findings

* Petal-related features (length and width) are very useful for distinguishing between species
* The dataset is well-structured and shows clear patterns between classes

##  Task 3: Heart Disease Prediction

###  Objective

In this task, the aim was to predict whether a person has heart disease based on medical data.

###  Dataset

Heart Disease UCI dataset from Kaggle.

###  What I did

* Loaded and explored the dataset
* Performed basic data analysis and visualization
* Split the data into training and testing sets
* Trained a Logistic Regression model

###  Evaluation

* Checked accuracy of the model
* Used confusion matrix to understand predictions
* Plotted ROC curve and calculated ROC-AUC score

###  Key Findings

* The model performed reasonably well in predicting heart disease
* Features like age, cholesterol, and heart rate had noticeable impact on results
